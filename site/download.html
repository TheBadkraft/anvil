One reference implementation, in C — bindings wrap it for other runtimes; anvil.js is the pure-JavaScript reader and writer for Node and browsers. Pick what matches where your code runs.

Native library — C / C++

anvil-v0.12.1-rc-linux-x86_64.tar.gz — static (libanvil.a) and shared (libanvil.so) release builds, plus the public headers. Linux x86_64 only today; other platforms build from source until real cross-platform CI exists.
Download 
tar -xzf anvil-v0.12.1-rc-linux-x86_64.tar.gz
gcc your_program.c -I anvil-v0.12.1-rc-linux-x86_64/include \
    -L anvil-v0.12.1-rc-linux-x86_64/lib -lanvil -o your_program

JavaScript — anvil.js (Node and browsers)

anvil.js-v0.12.1-rc.tar.gz — the JavaScript package. Pure JavaScript, with no native code and no WebAssembly: it runs in Node 18 or later and in any browser. It is now a reader and a writer. The reader has the same API as the Node.js binding, plus isNull(), and reads every document the way Anvil Native does (it passes all 1,867 cases of the shared conformance corpus). The writer is the AnvilWriter API of the Node.js binding and writes the same bytes as Anvil Native, in Node and in the browser. Two documented differences: 15 native writer cases are C-API-only (10 pass a null where a string is required, 5 write text that is not valid UTF-8), and value() writes a safe integer as an integer. Node ES modules can use named imports, and lastError() now carries code and name. The builder, types and schema validation are still to come in anvil.js. It replaces the Node.js and WebAssembly downloads below, which stay downloadable at v0.11.0-rc.
Download 
npm install ./anvil.js-v0.12.1-rc.tar.gz
import { parse, AnvilWriter, AnvilDialect } from 'anvil.js';   // or: const anvl = require('anvil.js')
const doc = parse('#!aml\nfoo := 1;');
doc.get('foo').asInt(); // 1
const w = AnvilWriter.create(AnvilDialect.AML);
w.statement('foo').value(1).finish(); // writes foo := 1;

In a browser, without a bundler, use dist/anvil.mjs (ES module) or dist/anvil.global.js (a <script> tag that defines window.anvl) from the tarball.

.NET — C#

anvil-net-v0.12.1-rc-linux-x64.tar.gz — a prebuilt managed assembly (Anvil.Net.dll) built directly on Anvil Native's vtable ABI, plus the native library it links against. Linux x64 (glibc) only today. There is no NuGet package, so reference the assembly directly; other platforms build from source.
Download 
using var doc = AnvilDocument.Load("config.anvl");
var server = doc.FindValue("server");
server["port"].AsInt(); // 8080

Python — ctypes

anvil-py-v0.12.1-rc-linux-x64.tar.gz — a pure-ctypes binding built directly on Anvil Native's vtable ABI, plus the native library it links against. No compiled extension module. Linux x64 (glibc) only today; not on PyPI, so put the extracted src directory on PYTHONPATH; other platforms build from source.
Download 
tar -xzf anvil-py-v0.12.1-rc-linux-x64.tar.gz
export PYTHONPATH="$PWD/anvil-py-v0.12.1-rc-linux-x64/src:$PYTHONPATH"
with AnvilDocument.load("config.anvl") as doc:
    server = doc.find_value("server")
    server["port"].as_int()  # 8080

These two are frozen at v0.11.0-rc and replaced by anvil.js. They stay downloadable at their existing addresses and nothing about them changes.

WebAssembly — browser, or any JS host

anvil-wasm-v0.11.0-rc.tar.gz — the compiled module (dist/) and a JS-facing wrapper (lib/index.js), with the same API as the Node binding below, including types, schema and the writer, plus a prebuilt browser bundle (dist/anvil.browser.js) for a plain <script> tag. Runs on any WebAssembly host. Module loading is async (WASM instantiation) — see the bindings guide for the one-line difference.
Download 
const anvil = require('anvil-wasm');
await anvil.ready();
const doc = anvil.parse('#!aml\nfoo := 1;');
doc.get('foo').asInt(); // 1

In a browser, without a bundler:

<script src="/vendor/anvil/anvil.browser.js"></script>
<script>
  // anvil.wasm is fetched from next to the script; say where it is otherwise:
  anvl.ready({ wasmUrl: '/assets/anvil.wasm' }).then(() => {
    anvl.parse('#!aml\nfoo := 1;').get('foo').asInt(); // 1
  });
</script>

Node.js — N-API

anvil-node-v0.11.0-rc-linux-x86_64.tar.gz — a prebuilt native addon plus its JS wrapper. Same API as the WebAssembly binding above (synchronous, no ready() needed). Linux x86_64 (glibc) only today; not published to a package registry, so install it from the tarball and build other platforms from source.
Download 
const anvil = require('anvil-node');
const doc = anvil.parse('#!aml\nfoo := 1;');
doc.get('foo').asInt(); // 1

Verify any download with SHA256SUMS (sha256sum -c SHA256SUMS in the folder holding the files). SHA256SUMS lists every release, current first; SHA256SUMS-v0.12.1-rc lists only this one (SHA256SUMS-<version> lists one release). The C library, .NET, Python and anvil.js downloads report the version 0.12.1-rc+420. The native downloads (C library, .NET and Python) are Linux x86_64 only; anvil.js runs wherever JavaScript does.
