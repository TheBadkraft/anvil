One reference implementation, in C — bindings wrap it for other runtimes; anvil.js is the pure-JavaScript implementation for Node and browsers. Pick what matches where your code runs.

v0.14.0-rc changes the language: only a top-level statement may have a base, so a base on a nested statement is now an error (4022). See the changelog before you upgrade. The C library and anvil.js are at v0.14.0-rc. The .NET and Python downloads below stay at v0.13.1-rc: there is no v0.14.0-rc build of either, and they do not have the v0.14 changes (they still accept a nested base).

JavaScript — anvil.js (Node and browsers)

anvil.js-v0.14.0-rc.tar.gz — the JavaScript package. Pure JavaScript, with no native code and no WebAssembly: it runs in Node 18 or later and in any browser. It is now complete: reader, writer, builder, types and schema. It has the same API as the Node.js binding, plus isNull(), and matches Anvil Native on the shared conformance corpora: the reader (1,920 cases), the writer (851 of 867), the builder (933 of 986) and the schema and type registry (561 of 561). The other writer cases (16) and builder cases (53) are C-API-only, because they pass a null, a handle of another builder or text that is not valid UTF-8, which JavaScript cannot express. value() writes a safe integer as an integer, and setIo({ read(path) }) lets a browser resolve include from files you supply. Small documents are slower than in the Node.js binding; the bindings guide lists the measured gaps. It replaces the Node.js and WebAssembly downloads below, which stay downloadable at v0.11.0-rc.
Download 
npm install ./anvil.js-v0.14.0-rc.tar.gz
import { parse, AnvilWriter, AnvilBuilder, TypeRegistry, Schema, AnvilDialect } from 'anvil.js';   // or: const anvl = require('anvil.js')
const doc = parse('#!aml\nfoo := 1;');
doc.get('foo').asInt(); // 1
const w = AnvilWriter.create(AnvilDialect.AML);
w.statement('foo').value(1).finish(); // writes foo := 1;

In a browser, without a bundler, use dist/anvil.mjs (ES module) or dist/anvil.global.js (a <script> tag that defines window.anvl) from the tarball.

.NET — C#

anvil-net-v0.13.1-rc-linux-x64.tar.gz — a prebuilt managed assembly (Anvil.Net.dll) built directly on Anvil Native's vtable ABI, plus the native library it links against. Linux x64 (glibc) only today. There is no NuGet package, so reference the assembly directly; other platforms build from source.
Download

Given a config.anvl like this:

server := {
    host := localhost;
    port := 8080;
};
using Anvil.Net;

using var doc = AnvilDocument.Load("config.anvl");
var server = doc.FindValue("server");
server["port"].AsInt(); // 8080

Python — ctypes

anvil-py-v0.13.1-rc-linux-x64.tar.gz — a pure-ctypes binding built directly on Anvil Native's vtable ABI, plus the native library it links against. No compiled extension module. Linux x64 (glibc) only today; not on PyPI, so put the extracted src directory on PYTHONPATH; other platforms build from source.
Download 
tar -xzf anvil-py-v0.13.1-rc-linux-x64.tar.gz
export PYTHONPATH="$PWD/anvil-py-v0.13.1-rc-linux-x64/src:$PYTHONPATH"
from anvil import AnvilDocument

with AnvilDocument.load("config.anvl") as doc:
    server = doc.find_value("server")
    server["port"].as_int()  # 8080

WebAssembly* (Unsupported) — browser, or any JS host

anvil-wasm-v0.11.0-rc.tar.gz — the compiled module (dist/) and a JS-facing wrapper (lib/index.js), with the same API as the Node binding below, including types, schema and the writer, plus a prebuilt browser bundle (dist/anvil.browser.js) for a plain <script> tag. Runs on any WebAssembly host. Module loading is async (WASM instantiation) — see the bindings guide for the one-line difference.
Download 
const anvil = require('anvil-wasm');
await anvil.ready();
const doc = anvil.parse('#!aml\nfoo := 1;');
doc.get('foo').asInt(); // 1

In a browser, without a bundler:

<script src="/vendor/anvil/anvil.browser.js"></script>
<script>
  // anvil.wasm is fetched from next to the script; say where it is otherwise:
  anvl.ready({ wasmUrl: '/assets/anvil.wasm' }).then(() => {
    anvl.parse('#!aml\nfoo := 1;').get('foo').asInt(); // 1
  });
</script>

Node.js* (Unsupported) — N-API

anvil-node-v0.11.0-rc-linux-x86_64.tar.gz — a prebuilt native addon plus its JS wrapper. Same API as the WebAssembly binding above (synchronous, no ready() needed). Linux x86_64 (glibc) only today; not published to a package registry, so install it from the tarball and build other platforms from source.
Download 
const anvil = require('anvil-node');
const doc = anvil.parse('#!aml\nfoo := 1;');
doc.get('foo').asInt(); // 1

Verify any download with SHA256SUMS (sha256sum -c SHA256SUMS in the folder holding the files). SHA256SUMS lists every release, current first; SHA256SUMS-v0.14.0-rc lists only v0.14.0-rc (SHA256SUMS-<version> lists one release). The C library and anvil.js downloads report the version 0.14.0-rc+554; the .NET and Python downloads (v0.13.1-rc) report 0.13.1-rc+479. The native downloads (C library, .NET and Python) are Linux x86_64 only; anvil.js runs wherever JavaScript does.
